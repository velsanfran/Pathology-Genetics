Pathology & Genetics for RimWorld

A comprehensive RimWorld mod focused on adding deep, realistic, and punishing medical mechanics, infectious diseases, and hereditary transmission vectors.
Features

    Prion Disease Integration: Ingesting human meat introduces a realistic risk of contracting a degenerative prion infection.

    Hereditary Transmission: Infected parents can pass down conditions like prions to newborns instantly upon world spawn/birth.

    Airborne Spread System: Custom hediff components (HediffComp_AirborneSpread) allowing pathogens to transmit through environmental factors.

    Organ Rejection & Surgery Mechanics: Expanded medical options and surgical procedures.

    Custom Mod Settings: Fully configurable sliders and parameters to tweak infection rates and difficulty.

Technical Details

    Built for RimWorld (C# / .NET Framework) using Harmony.

    Strict namespace-to-folder architecture and C# 7.3 compatibility for seamless performance.
